# 🧮 Калькулятор на Python

Простой графический калькулятор, созданный на **Python** с использованием библиотеки **Tkinter**.

## 📌 Возможности

* ➕ Сложение
* ➖ Вычитание
* ✖️ Умножение
* ➗ Деление
* 🔢 Работа с числами
* 🖥️ Графический интерфейс
* ⌫ Удаление введённых данных
* 🧹 Очистка выражения

## 🛠️ Используемые технологии

* **Python 3**
* **Tkinter** — создание графического интерфейса

## 🚀 Запуск

### 1. Установите Python

Скачать Python можно с официального сайта:

https://www.python.org/downloads/

### 2. Скачайте репозиторий

```bash
git clone https://github.com/kurmatka/kurmatka.git
```

Перейдите в папку проекта:

```bash
cd kurmatka
```

### 3. Запустите калькулятор

```bash
python "калькулятор на tkinter.py"
```
